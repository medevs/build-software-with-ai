    Your First Week

    You now have every piece: a context layer, a repeatable loop, and a tool to run it on. This lesson turns that into seven concrete days on a real project.

    The arc you just walked

    Stand back for a second. This course moved you through four stages, and it's worth naming them because they're also the order you should keep growing in after today:

    1. Use. Get a working loop running before optimizing anything — feel the difference between firing off a prompt and running a real process.
    2. Understand. Learn each building block on its own — rules, skills, connections, sub-tasks, guardrails, and search — so you know what each one is actually doing for you.
    3. Evolve. Combine those building blocks into bigger, more autonomous workflows instead of running each one by hand every time.
    4. Scale. Move reliable loops off your screen — parallel, remote, or automated — so the system works beyond one person at one keyboard.

    You'll keep cycling through these four stages on every new project, every new tool, every new part of your codebase. That's not a flaw — it's the design. The plan below is one lap through Use, on a project you actually care about.

    Seven days, one real project

    Pick a project — new or existing, doesn't matter which — and work through this. Don't rush it into one sitting; let each day's habit settle before adding the next.

    If a day slips Repeat it rather than skip ahead. The habit matters more than the calendar — a slower first week that actually sticks beats a fast one you abandon.

    The one throughline, restated

    Every lesson in this course has been one long argument for a single idea: the bottleneck was never the model — it's the system around it. The context layer and the loop you practiced this week are that system. The tool you picked on Day 1 is replaceable; the habits you built around it are not.

    Keep going Two places to return to as you keep building: the resources page for reference material, and the first-week checklist if you want this plan as a simple list to check off day by day.

    Check yourself

    Quick recall: what are the four steps of the core loop, in order?

    What's the four-stage arc this course walked you through?

    If you remember only one sentence from this whole course, which is it?

    The one thing to remember

    You don't need a perfect system on day one — you need a working loop you run again tomorrow. Everything you've learned compounds from here, one small, repeatable rep at a time.

    Reflect & discuss Come back after your first week and tell the rest of the course what you built, what broke, and what surprised you. Post it in the course discussions — the community is where this system keeps getting sharper, for you and for everyone else running the same seven days.
