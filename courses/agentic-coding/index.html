How to use this course

Work through it in order — or follow the map

The 30 lessons are grouped into 7 modules that build on each other, from “why you need a system” to “put it to work on real code this week.” Each lesson is short, concrete, and ends with a quick self-check. Beginners should go top to bottom; the map above lets you see how every idea connects and jump around once you know the terrain.
